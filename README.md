# AIML-intern-project-3-AI-dungeon-story-generator
Create interactive fantasy stories using generative AI

## Tools ##
Python, GPT-2/GPT-Neo, Streamlit

## Actions Performed ##
1. Load pretrained GPT-2 from Hugging Face
2. Build prompt-based input
3. Generate story continuation
4. Show multiple continuations
5. Save story as text file
6. Add genre selection (fantasy, mystery, etc.)
7. Deploy via Streamlit

## Deliverables ##
1. Streamlit App: https://aiml-intern-project-3-ai-dungeon-story-generator-p6ydiuma92pew.streamlit.app/
2. Interactive Story Samples: UI-1.png, UI-2.png, UI-3.png
3. Codebase: app.py, story.py, ai_story.py
